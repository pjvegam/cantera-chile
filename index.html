Los ratings usan las mismas fórmulas de tu planilla. Con forma les suma el modificador forma/10 − 1; apagado, mide la habilidad pura, que es lo que sirve para proyectar. equipo bot es un equipo sin manager: nadie entrena a esos jugadores. skill oculta es cuando el manager las esconde; ahí se muestra la última lectura real y, si nunca la hubo, un guión. Cada posición tiene su propia escala, así que los números solo se comparan hacia abajo dentro de una columna, nunca de lado entre columnas. Haz clic en el título de una columna para ordenar por ella; queda resaltada. Haz clic en un jugador para ver el desglose y abrir su ficha en Sokker.

Cómo se calcula cada posición
PosiciónFórmulaPeso
Portero 3·(Por+F) + 2·(Rap+F) + Pas/3 + F5,3
Defensa 4·(Def+F) + 3·(Rap+F) + (Téc+F)8
Lateral (Defensa + M.Def) / 212
M.Def 4·(Rap+F) + 4·(Pas+F) + 3·(Téc+F) + 3·(Def+F) + 2·(Cre+F)16
M.Of 4·(Rap+F) + 4·(Pas+F) + 3·(Téc+F) + 3·(Cre+F) + 2·(Def+F)16
M.Prom (M.Def + M.Of) / 216
Delantero (Ano+F) + (Rap+F) + (Téc+F)3

F es el modificador de forma, forma/10 − 1, y vale 0 con el interruptor con forma apagado. La columna Peso es la suma de los coeficientes: ahí se ve por qué un M.Def llega a ~200 y un Delantero a ~41, y por qué no tiene sentido compararlos entre sí. Son las fórmulas tal cual estaban en la planilla, incluido que Portero divida Pas por 3 y le sume F aparte.
